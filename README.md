# LifeOps for Obsidian

Your LifeOps, as a vault: goals with their tasks, notes, days, events, areas, reminders and goal maps as files you can read and edit in Obsidian. What you type saves back to your LifeOps. Runs on Obsidian for desktop and phone.

## Install

Until it is in the community store, install it through BRAT (Beta Reviewers Auto-update Tool), which is in the store:

1. In Obsidian, make a vault for it, or use one you have. Keep the vault on the device: not in iCloud or another synced folder, because the plugin writes the vault from your LifeOps on each device.
2. Settings, Community plugins, turn them on. Browse, install BRAT, enable it.
3. In BRAT's settings, Add beta plugin, and enter `Cognizant-Coaching/obsidian-lifeops`.
4. Enable LifeOps. In its settings, type your LifeOps address and sign in with your LifeOps username and password.

The LifeOps folder fills in within a minute.
